# MUSE Legacy Experience Flow — Reference Only

This file exists so Codex knows older MUSE interaction ideas still exist, but it is **not** the current source of truth for console ordering or naming.

## Legacy concepts that remain useful

The previous flow established several interaction ideas that may still be reused when they do not conflict with current implementation plans:

- local registration/session handoff,
- recipient/relationship context,
- three-photo capture constraint,
- capture review and retake branch,
- optional short machine note,
- five-parameter dial/tuning grammar,
- generated letter result,
- five reflection questions,
- side-by-side letter comparison,
- final stance choices: Convenience / Control / More Human,
- token wall as a physical collective ritual rather than a leaderboard,
- postcard/print handoff,
- shared physical vocabulary using dial + arcade buttons.

## Current override

The current implementation reverses the older first/second-console conceptual order:

1. **Arcade 1 = Human + AI**. Human material comes first; AI supports/enhances it.
2. **Arcade 2 = AI-only**. It inherits visitor/recipient context, accepts a short prompt and intensity settings, exposes machine analysis, and generates the alternative letter.
3. Reflection compares Human + AI with AI-only.

Do not restore older `Ex-Love` / `Next Love` naming or an AI-first Arcade 1 unless explicitly instructed.

For exact current screen IDs and responsibilities, use `docs/implementation/07-screen-inventory.md`.
